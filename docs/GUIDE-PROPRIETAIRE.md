# Guide de gestion du site — Doodles R Us

Ce guide explique comment gérer les informations sur les chiots sans modifier le code du site.

## Accéder au tableau de bord

1. Ouvrir https://app.pagescms.org.
2. Se connecter avec le compte autorisé.
3. Sélectionner le site **Doodles R Us**.
4. Ouvrir la section **Chiots et disponibilités**.

## Ajouter un chiot

1. Cliquer sur l'option permettant d'ajouter un chiot.
2. Inscrire son nom.
3. Choisir son statut : Disponible, Réservé ou Adopté.
4. Rédiger une courte description en français et en anglais.
5. Ajouter une photo si elle est disponible et autorisée à être publiée.
6. Si une photo est ajoutée, remplir les descriptions alternatives en français et en anglais.
7. Enregistrer les modifications.

**Important :** Ne jamais ajouter de renseignements personnels sur les familles adoptantes.

## Modifier la disponibilité

1. Ouvrir **Chiots et disponibilités**.
2. Sélectionner le chiot concerné.
3. Modifier le champ **Disponibilité**.
4. Enregistrer.

## Modifier les photos

1. Ouvrir la fiche du chiot.
2. Remplacer ou ajouter la photo.
3. Vérifier que la photo correspond au bon chiot.
4. Mettre à jour les descriptions alternatives.
5. Enregistrer.

Utiliser des photos nettes, bien éclairées et dont la publication est autorisée.

## Modifier les coordonnées

1. Ouvrir Pages CMS et sélectionner Doodles R Us.
2. Choisir **Coordonnées**.
3. Modifier l'adresse courriel, le numéro de téléphone ou le lien Facebook.
4. Laisser un champ vide si ce moyen de communication n'est pas offert.
5. Enregistrer les modifications.

**Important :** Utiliser uniquement les coordonnées officielles de l'élevage.

## Modifier la présentation de l'élevage

1. Dans Pages CMS, ouvrir **À propos de l'élevage**.
2. Modifier la présentation et l'histoire dans la section **Version française**.
3. Mettre à jour les textes correspondants dans **English version**.
4. Relire les deux versions avant d'enregistrer.
5. Enregistrer les modifications.

Les modifications seront prises en compte lors du prochain déploiement réussi du site.

## Bonnes pratiques

- Vérifier les renseignements avant leur publication.
- Éviter de partager une adresse résidentielle privée.
- Ne pas publier de renseignements personnels sur les familles adoptantes.
- Utiliser seulement des photos et des textes dont la publication est autorisée.
- Contacter le responsable technique si une modification provoque une erreur.

## Retirer une annonce

Avant de supprimer une fiche, vérifier que les informations ne sont plus nécessaires. Si le chiot a rejoint sa famille, il est possible de modifier son statut à **Adopté**.

## En cas de problème

Si une modification n'apparaît pas sur le site, vérifier qu'elle a bien été enregistrée. La mise à jour du site peut nécessiter un nouveau déploiement.

Si le problème persiste, contacter la personne responsable de la maintenance technique. Éviter de répéter plusieurs fois la même modification.
